# SOXL B전략 시그널 봇

`SOXL B전략.txt` 의 규칙을 감시해서 **매수·매도 신호가 나면 텔레그램으로 알린다.**
주문은 내지 않는다. 증권사 계좌와 연결되지 않는다.

```
진입   RSI(12) ≤ 25            (1시간봉 종가)
발동   평가수익 +10% 도달 → 트레일링 켜짐
청산   발동 후 고점 대비 -3%
손절   진입가 -30%             ← 이 전략의 본체
```

## 구조

```
GitHub Actions (15분마다)          Cloudflare
  bot.py                            Worker "soxl-bot"
   ├ Yahoo 5분봉 60일 조회            ├ POST /tg      텔레그램 명령 (즉시)
   ├ 정규장 → 1시간봉 (7봉/일)        ├ GET /d/{경로}  대시보드
   ├ RSI(12) Wilder                  └ cron          감시견 (매일 07:00 KST)
   ├ 상태머신                                │
   └ 텔레그램 발송                    KV "STATE"  ← 상태 단일 원본
```

`bot.py` 는 **멱등**하다. "지금 몇 시냐"가 아니라 "KV 의 `last_bar` 이후
확정된 봉이 있냐"로 판단하므로, cron 이 늦거나 건너뛰어도 다음 실행이
밀린 봉을 전부 처리한다.

## 봉 구조 — 절대 건드리지 말 것

ET 09:30~**15:59** 를 UTC 정각으로 resample → **하루 7봉**.

ET 16:00 의 1분짜리 봉을 포함하면(8봉/일) 5년 누적이
**+2,600% → +518%**, MDD 가 **-66% → -76%** 로 무너진다.
`strategy.py` 의 `RTH_CLOSE` 를 고치면 다른 전략이 된다.

## 검증

```bash
python verify_backtest.py     # Polygon 원본 CSV 필요 (로컬 전용)
```

문서의 **+2,600% / MDD -66.3% / 58거래 / 승률 87.9%** 를 재현하면 PASS.
`strategy.py` 를 수정했으면 반드시 다시 돌린다.

## 텔레그램 명령

| 명령 | 동작 |
|---|---|
| `/status` | 현재 상태와 트리거까지 거리 |
| `/entry 123.45` | 진입가를 실제 체결가로 정정 |
| `/skip` | 신호 났지만 안 삼 → 미보유로 되돌림 |
| `/sold` | 매도 완료 → 미보유 |
| `/hold 123.45` | 수동으로 보유 등록 |
| `/peak 130.00` | 진입후 고점 수동 보정 (액면분할 등) |
| `/id` | 이 대화의 chat_id 확인 |

`/skip` 은 "이번 봉만 무시"가 아니라 **미보유로 되돌리는** 명령이다.
RSI 가 계속 25 이하면 다음 봉에 또 신호가 온다.

## 설치

`SETUP.md` 참조.

## 로컬 테스트

```bash
pip install -r requirements.txt
python bot.py --local --dry                  # KV·텔레그램 없이 동작 확인
python bot.py --local --dry --force-summary  # 일일 요약 미리보기
```

## 알아둘 것

- **액면분할** 시 KV 의 `entry`·`peak` 가 조정되지 않아 하드스탑이 오발동한다.
  분할이 있으면 `/entry`·`/peak` 로 직접 보정할 것.
- **알림을 놓칠 수 있다.** 미국장은 한국 새벽이다. 하드스탑 알림은
  15분 간격으로 3회 발송되지만, 그래도 못 보면 다음 날 아침에 실행하게 된다.
- **yfinance 는 비공식 스크래퍼다.** 깨지면 `TWELVEDATA_API_KEY` 를
  Secrets 에 넣어두면 자동으로 예비 소스로 넘어간다.
- **GitHub 60일 규칙** — 저장소에 활동이 없으면 스케줄 워크플로가 자동
  비활성화된다. 하루 1회 `signals.log` 커밋으로 활동을 유지하고,
  그래도 멈추면 Cloudflare 감시견이 텔레그램으로 알린다.
